# Just Watched

Prototype for a movie-review app reduced to one job: **log a take in the moment after you finish a movie**.

## Assumption under test

People will actually use this if it fits the existing post-watch moment — no account, no feed, no search, no extra steps.

## How to try it

Open `index.html` in a browser (phone width is the intended experience). On Android Chrome, use **Add to Home screen** so opening it is one tap after the credits.

1. Type the title.
2. Tap stars.
3. Optional one-line note.
4. Hit **Log it**.

Reviews stay in this browser’s local storage.
